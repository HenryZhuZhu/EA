DIMM 双列直插内存模组

把多颗 DRAM IC 焊在一块 PCB 上、金手指两面独立引脚，就是插到主板上的"内存条"。按用途/形态分 RDIMM / UDIMM / SODIMM / CAMM。

8~36 颗 IC + PCB + 金手指
2 DIMM 家族：四种常见内存模组 — 同样是"内存条"，因应用场景不同而形态/电气不同
UDIMM Unbuffered DIMM · 无缓冲 消费级 / 台式机
最"原始"的桌面内存条。地址/命令信号 直连 DRAM，无寄存器缓冲。
成本低、延迟低，但单条容量与稳定性上限较低，容量大时对 CPU 负载压力大。
RDIMM Registered DIMM · 带寄存器 服务器 / 数据中心
在地址/命令线上加了 寄存器 (Register / RCD) 做缓冲（图中紫色芯片），减轻 CPU 内存控制器负载。
可堆更大容量、更稳定，常配 ECC；延迟略高、价格贵。服务器主流。
SODIMM Small Outline DIMM · 小型化 笔记本 / 迷你机
更短更小的 DIMM，为笔记本/一体机/迷你主机的空间设计（约桌面条的一半长）。
电气上多为无缓冲(类 UDIMM)，也有 ECC 版本。是移动设备的标准可插拔内存。
CAMM(2) Compression Attached Memory Module 新一代 / 超薄本
压缩贴合式新标准 (JEDEC CAMM2)：模组 平铺并用螺丝/触点压接到主板，而非竖插金手指。
更薄、走线更短、频率更高，可替代 SODIMM，兼容 DDR5/LPDDR5。面向超薄本与高性能移动平台。
3 四种模组速查对比
模组 全称 / 含义 缓冲寄存器 主要场景 形态特点 典型容量/稳定性
UDIMM Unbuffered 无缓冲 DIMM 无 台式机、消费级 标准长条，全长 容量中等，成本低、延迟低
RDIMM Registered 带寄存器 DIMM 有 (RCD) 服务器、工作站、数据中心 标准长条 + 寄存器芯片，多配 ECC 容量大、最稳定，价格高
SODIMM Small Outline 小型 DIMM 一般无 笔记本、迷你主机、一体机 短小（约桌面条一半），竖插 容量中等，节省空间
CAMM2 Compression Attached MM 压缩贴合 视规格 超薄本、新一代移动/高性能平台 平铺压接（非金手指竖插），超薄 高频、低延迟，替代 SODIMM
Wafer 晶圆 Die/IC 颗粒 DIMM 模组 寄存器/RCD（RDIMM） 金手指/触点
易混点提示： ① Die 与 IC：Die 是晶圆上切下的裸晶粒；IC 是封装后的成品颗粒——DRAM 语境下常直接叫"内存颗粒"。 ② DIMM 是"模组"级，不是芯片级：一条 DIMM = 多颗 IC + PCB。 ③ RDIMM/UDIMM 是电气区别（有无寄存器缓冲），SODIMM 是尺寸区别（小型化），CAMM 是连接方式区别（压接替代竖插），三者划分维度不同。 ④ ECC 与 R/U 无关：UDIMM 也可以带 ECC，RDIMM 也可无 ECC，只是服务器多为 ECC RDIMM。
