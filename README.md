## 一句话范围

V0.2 聚焦三件事：
1. **思维导图重构**（信息密度、拖拽/复制、路径折叠与标记、撰写引导）——需求最密集、价值最高；
2. **任务详情 & 已完成结果可视化**——让执行者"进来就知道做什么、做完能看到结果"；
3. **协同闭环**（流转日志、附件与下载权限、WS 文档结案、@人员、权限记忆）。

辅以**管理者看板**升级与**全局引导/版本说明**。

## 当前 V0.1 已具备（作为基线）

- Case 中心：聚焦视图（智能分组卡片）+ 全部列表（多维筛选/排序）+ 自定义卡片
- Case 详情：概览、影响字段、紧凑版"分析过程与结论"入口、思维导图、节点目录、任务动态抽屉
- 思维导图：小卡 + Hover 放大、紧急度底色、结论有效性标签、标记整条线高亮、临期红标、横/竖布局、视图筛选（全局/未完成/有效路径）、节点常驻新增按钮、语音备注录制与回放
- 新建 Case：影响必填字段、AI 润色 + 语音输入、产品/物料/失效信息归组
- 全局：PC 端专用
