两步，接入你的工具

在 Cimicode 或 Workspace 里声明 EA Skills 源，Agent 即可发现并调用全部能力。

.cimicode/skills.toml
# 声明 EA 能力源，Agent 自动发现全部 Skill
[[skills]]
source   = "ea"
endpoint = "https://ea.internal/skills"
auth     = "$EA_TOKEN"
expose   = ["createCase", "runChipDNA", "riskAlert", "genReport"]
workspace.config.js
import { ea } from "@ea/skills"

export default {
  skills: [
    ea({ endpoint: "https://ea.internal/skills", token: process.env.EA_TOKEN })
  ]
}

典型场景

从异常一键开 Case

Agent 发现良率异常，直接调用 EA 开出可追踪的失效调查 Case，并指派负责人。

ea.createCase(...)

失效比对与定位

把批次交给 ChipDNA 比对历史指纹，命中已知失效模式并给出置信度与根因线索。

ea.runChipDNA(...)

风险预警与汇报

一句话汇总团队多维指标输出风险清单，再把 Case 结论生成结构化汇报草稿。

ea.riskAlert() · ea.genReport()
